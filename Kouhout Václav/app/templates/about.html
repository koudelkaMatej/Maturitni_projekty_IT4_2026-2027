Prostor pro učení.
A praktické řešení.

B2B katalog nábytku s plánovaným konfigurátorem projektů a cenovými nabídkami. Projekt Václava Kohouta.

Co už funguje

  • Pět veřejných stránek a společná navigace.
  • Ukázkový katalog s hledáním a kategoriemi.
  • Responzivní vzhled ve vlastním CSS.
  • Vlastní chybová stránka pro neexistující adresy.

Co bude následovat

  • MySQL a skutečné načítání produktů.
  • Registrace, přihlášení a soukromé projekty.
  • Ukládání cenových nabídek a administrace.
  • AI vizualizace a případně export nabídky do PDF.

Jak spolu části komunikují

Prohlížeč odešle požadavek → Flask vybere Python funkci → Jinja doplní HTML šablonu → prohlížeč zobrazí stránku.

V další fázi Python načte data z MySQL pomocí ručně psaných parametrizovaných SQL dotazů.

Použité technologie

Python, Flask, Jinja, HTML5 a CSS3. Bez CSS frameworku, ORM a platební brány.

ER diagram a podrobné datové toky jsou součástí dokumentace v repozitáři.
